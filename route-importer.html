Affiliated Hub Manager

Manage affiliated hubs in Supabase. Affiliated hubs are blocked as origins for scanning, importing and optimisation, and are excluded as destinations. Changes never delete routes, pricing or X380Plus allocations.

Sign in to manage affiliations. This session is kept in memory only.

Removing affiliation changes origin restrictions and destination exclusions. It does not release aircraft or delete data. Refresh the Rotation Optimiser after changes.
