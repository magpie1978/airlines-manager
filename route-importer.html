Security and connection details

The server requires a valid Supabase user session whose email is explicitly allowlisted (AM_ALLOWED_EMAILS). The shared session is managed by the main website and cleared on sign-out. Do not use your Supabase Dashboard password unless it is also the Auth user password. The server scans and upserts into Supabase using its own configuration. The browser does not directly write to Supabase tables. Use only a function secured for your account; the existing function must be reviewed for authorization before exposing it publicly.

Additional data requirements

The optimiser requires a matching pricing.csv or Supabase pricing dataset for the hub. Use your existing authenticated Edge Function to collect route audit and pricing data; the importer invokes the Edge Function to scan the selected hub, but does not fabricate missing metadata.

For the game-side scan, open Airlines Manager Network ↗ , choose the required hub, and run your owned-route exporter. Then upload its CSV above.

Affiliated Hub Manager (expand to manage hubs)

Manage affiliated hubs in Supabase. Affiliated hubs are blocked as origins for scanning, importing and optimisation, and are excluded as destinations. Changes never delete routes, pricing or X380Plus allocations.

Sign in to manage affiliations. This session is kept in memory only.

Removing affiliation changes origin restrictions and destination exclusions. It does not release aircraft or delete data. Refresh the Rotation Optimiser after changes.
